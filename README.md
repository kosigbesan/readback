# ReadBack

Your interview prep, read aloud on the drive.

ReadBack takes the documents you already have (the job spec, the question pack, your own
notes) and reads them back to you one sentence at a time, hands free, so the drive to the
interview is study time. It is a mobile web app. Add it to your home screen and it behaves
like a native app, and it keeps working with no signal.

Live: https://kosigbesan.github.io/readback/

## What it does

- Reads PDF, DOCX, TXT, MD, RTF, HTML, EPUB, PPTX, ODT, CSV, and pasted text
- Detects questions automatically (Q: prefixes, question marks, "Tell me about..." openers)
- Interview drill: reads the question, goes quiet so you can answer out loud, then reads the
  model answer
- Driving mode: large controls, one tap play and pause, sentence skip and section repeat
- Follows along in the text, highlighting the sentence being spoken
- Sections from headings, so you can jump to Behavioural or Your questions
- Remembers your place in every document
- Works with car stereo and steering wheel buttons through the Media Session API
- Keeps the screen awake while reading

## What it deliberately does not do

- No accounts. There is a device id and a plan, not a login, so there is no library sync
  between phones yet. Documents live in this browser and can be moved with the backup button.
- No OCR. A scanned PDF is a picture of a page and has no text layer, so it needs OCR before
  ReadBack can read it.
- No CarPlay or Android Auto tile. A web app cannot have one, whichever builder you use.
  Bluetooth media controls and the car screen work through the Media Session API, and that
  is the ceiling on the web.

## Plans

| Plan | Price | What you get |
|---|---|---|
| Free | $0 | 1 document, 10 minutes of listening, device voices |
| Interview Sprint | $19 once, 30 days | Unlimited everything, 60k voice characters, does not renew |
| Pro | $7.99/month | Unlimited everything, 150k voice characters a month |
| Pro, annual | $49/year | Same as Pro, billed yearly |

The thinking behind this shape: interview prep is an episodic, high stakes purchase. Most
people do not want a yearly subscription for one interview loop, so the sprint pass is the
plan that matches how the product actually gets used, and Pro is there for people in an
active search. Speechify costs $139 a year, which is a lot to spend on a single interview.

## The service

Payments and the premium voice cannot live in the browser, so there is a small Node service
in `server/`. It holds the Stripe integration, decides which plan a device is on, and proxies
the voice so no API key is ever shipped to the phone. See `server/README.md`.

**You do not need a Stripe account to see the whole thing work.** While no Stripe key is set,
the service serves its own test checkout. Pressing Buy in the app opens a page that says no
card is charged, and completing it really does upgrade the device. Set `STRIPE_SECRET_KEY` and
those routes stop existing, so real Checkout takes over and nobody can give away a paid plan.

Deploy configs are already in the repo: `render.yaml` for a Render Blueprint, `.replit` for
Replit, and `server/Dockerfile` plus `server/Procfile` for anything that runs containers.

**Without a service connected the app still works.** It runs on device voices, purchases
unlock locally and say so plainly, and it never pretends a payment happened. Connect a
service URL in Setup and the same buttons become real Stripe Checkout.

**Premium voice** is implemented two ways, in this order of preference:

1. Through the service, which keeps the key server side and meters characters against the
   plan. A free plan gets a 402 and is shown the upgrade sheet rather than silently failing.
2. Falling back to the user's own ElevenLabs key, if they have one and no service is
   connected. The cost then sits on their account, not yours.

**Offline grace.** Whatever plan the service last reported is cached, so a device that has
paid keeps working in a car park with no signal. The client licence is only ever a hint for
the interface; the service is what enforces the plan, because the service is what gets billed.

## Tests

Three suites, none of which need the network or spend money:

```
python -m http.server 8765 &       # once, for the client suite
node test/run.js                   # 34 checks: parsing, player, driving mode, freemium gate
node test/live.js                  # the deployed site, not the local copy
node test/integration.mjs          # 41 checks: app and service talking, in a real browser
cd server && npm test              # 85 checks: licences, Stripe, webhooks, voice proxy
```

Screenshots from the client suite land in `test/shots/`.

## Layout

```
index.html          the whole app: UI, extractors, player, plans
service-worker.js   offline cache for the shell and the parsers
manifest.json       PWA manifest
vendor/             pdf.js, mammoth, JSZip, vendored so it works offline
icons/              generated by gen_icons.py
server/             the API: licences, Stripe, webhooks, voice proxy
  index.js          all the endpoints, exported as createApp for testing
  lib/plans.js      the catalogue and the licence shape
  lib/store.js      swappable storage, JSON file by default
  test.js           85 checks, mocked voice upstream, real Stripe signatures
gen_icons.py        draws the app icons with Pillow
gen_tests.py        builds the sample documents the tests use
test/run.js         end to end checks in headless Chrome
test/live.js        verification against the deployed URL
test/integration.mjs  app plus service, together
```

## Running it locally

Serve the folder over HTTP (service workers need a real origin, not `file://`):

```
python -m http.server 8765
# then open http://127.0.0.1:8765/
```

## Tests

`node test/run.js` drives a real headless Chrome against a local server on port 8765. It
checks sentence splitting, question detection, extraction of a real PDF, DOCX and TXT, the
reader and player state machine, seek and section tracking, driving mode, the media session
wiring, and the freemium gate. Screenshots land in `test/shots/`.

```
npm install puppeteer-core
python -m http.server 8765 &
node test/run.js
```
